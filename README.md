# baayer-adam.ru

Сайт-визитка личного байера **BAAYER_ADAM** — выкуп и доставка товаров
из-за рубежа (США, Европа, Китай, Турция) с доставкой по всей России.

Статический сайт без сборки: HTML + CSS + немного ванильного JS.
Хостится на GitHub Pages, домен подключён через `CNAME`.

## Структура

```
index.html            вся страница целиком
404.html              страница ошибки
robots.txt            + sitemap.xml — для поисковых систем
assets/css/style.css  стили
assets/js/main.js     меню, цели Метрики
assets/js/animations.js  reveal при скролле, глобус (Cobe)
assets/img/           логотипы, og-карточка, фото магазина
assets/fonts/         Montserrat и Bebas Neue (woff2, свой хостинг)
```

Шрифты лежат у нас, а не грузятся с Google: так текст рисуется без похода
на сторонний домен и IP посетителей не уходит в Google. `@font-face`
с `unicode-range` в начале `style.css` — браузер скачивает только тот
набор символов, который реально нужен. Bebas Neue кириллицы не содержит,
русский текст в нём осознанно падает на Arial.

## Аналитика

Яндекс.Метрика — счётчик `111573111`, подключён внизу `index.html`.
Номер продублирован в `window.YM_ID`: его читают цели на клики
в мессенджеры из `assets/js/main.js`. При смене счётчика поменяйте
номер в обоих местах.

Цели, которые должны быть заведены в интерфейсе Метрики
(тип «JavaScript-событие»):

```
whatsapp   telegram   tg_store   instagram
```

## Файлы подтверждения прав — не удалять

```
yandex_20bd70bf58b18a26.html   Яндекс.Вебмастер
google2847d98147016014.html    Google Search Console
```

Обе системы периодически перепроверяют права и снимают подтверждение,
если файл пропал. Поэтому мета-теги верификации в `<head>` не нужны.

## Локальный запуск

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Открывать `index.html` двойным кликом (`file://`) **не нужно** — браузер
блокирует ES-модули по CORS, и часть анимаций не запускается.

## Правка FAQ

Тексты вопросов и ответов дублируются в двух местах: в секции `#faq`
и в блоке `FAQPage` внутри JSON-LD в `<head>`. При правке нужно менять
**оба**, иначе поисковики отметят несоответствие разметки.
